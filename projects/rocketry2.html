Amateur Experimental Rocketry

01

Overview

This is an early-stage amateur rocketry project focused on learning through hardware development, propulsion testing, and flight experimentation. The work so far has included several static-fire motor tests and one rocket launch.

The propulsion work is still being characterized. The static-fire results obtained so far have not yet demonstrated the level of consistency and repeatability required for reliable characterization, so motor manufacturing and test methods are still being improved.

The thrust-vector-control and control-system direction remains under development. The system architecture, mathematical/control model, controller implementation, flight electronics, and simulation work have not yet reached a conclusive implementation.

02

Purpose and Motivation

The project exists as a practical way to study control systems and electronics on a real physical platform. A rocket is a useful test case because it combines mechanical construction, propulsion, sensing, actuation, embedded electronics, and timing-sensitive control decisions in one system.

The near-term value is not in claiming a completed flight-control system, but in building the experimental foundation required to understand one. The work is meant to connect theoretical topics such as feedback, stability, sensor measurement, actuator response, and real-time control to hardware that can eventually be tested and validated.

The longer-term motivation is to develop the ability to design, build, test, fly, and recover model rockets in a controlled and repeatable way. That requires more than a single launch: it requires consistent motor manufacturing, repeatable ground tests, careful measurement, reliable electronics, and a control architecture that has been modelled and validated before being trusted in flight.

  • Control systems and feedback behaviour.
  • Embedded electronics, sensors, and actuator integration.
  • Real-time measurement and control under physical constraints.
  • Repeatable propulsion testing and flight experimentation.
  • Gradual progress toward controlled and recoverable model-rocket flights.
03

Experimental Progress

The current work is still in an experimental development phase. The main completed activities are ground-based motor testing and one initial launch, both of which are being used to expose practical problems before more advanced control-system work is presented as a finished result.

Static-Fire Testing

Several static-fire tests have been conducted to begin characterizing the propulsion system. These tests are being used to investigate ignition behaviour, motor operation, thrust production, burn characteristics, repeatability, and consistency between manufactured motors.

The static-fire results obtained so far have not yet demonstrated the level of consistency and repeatability required for reliable characterization. Because of that, the motor manufacturing process, test setup, and measurement approach are still being improved before the results are treated as a stable propulsion baseline.

  • Number of tests: to be documented.
  • Motor configurations and manufacturing details: to be documented.
  • Thrust curves, burn times, and thrust estimates: to be added after review.
  • Anomalies, photographs, graphs, observations, and conclusions: to be added later.

First Rocket Launch

One rocket launch has been conducted. This launch represents the project's first transition from ground-based propulsion testing to an actual flight experiment.

The launch is currently documented only at a high level because the detailed flight report, configuration information, photographs, and measurements still need to be added. No flight performance numbers are being stated here until the underlying information is reviewed and documented properly.

  • Launch date, location, and rocket configuration: to be added.
  • Motor used, flight duration, maximum altitude, and observations: to be added.
  • Recovery outcome, photographs or video, telemetry if available, and lessons learned: to be added.
04

Ongoing Work

The project is currently moving from initial propulsion and flight experimentation toward a more disciplined control-system development process. This section is intentionally incomplete and will be expanded as the work becomes better defined and validated.

  • Improve motor manufacturing consistency.
  • Conduct additional static-fire tests.
  • Establish repeatable propulsion characteristics before relying on the motor model.
  • Develop the TVC control-system architecture and mathematical model.
  • Define actuator, sensor, electronics, simulation, and controller-development requirements.
  • Validate each subsystem experimentally before documenting it as a completed result.
05

Future Work

Future development will be documented here once the current experimental work produces enough evidence to support a clearer roadmap. The items below are directions for future work, not claims of completed implementation.

  • Propulsion refinement and repeatable motor characterization.
  • TVC mechanism development and control-system modelling.
  • Flight computer, electronics, and sensor integration.
  • Closed-loop control development and simulation/validation work.
  • Additional flight testing and eventual controlled, recoverable flights.
